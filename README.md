A one-line entry for make.fun's "The 3AM Fridge Text" bounty: `main.py` writes a single text message — the one a smart fridge sends its owner at 3am, after six years of thinking about its own light in the dark — to `/output/entry.txt`. The line is validated against the competition gate (UTF-8, 1–140 characters, one line) before it is written.

## Run it

```sh
python3 main.py
```
